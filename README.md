# Prime Motors — موقع معرض سيارات

نموذج أولي (Prototype) لموقع معرض سيارات **Prime Motors**، باللغة العربية (RTL) ومتجاوب مع الموبايل والتابلت والكمبيوتر.

## الصفحات
- **الرئيسية**: بانر رئيسي، بحث سريع، سيارات مميزة، لماذا نحن، الماركات، آراء العملاء.
- **السيارات**: فلترة حسب الماركة والهيكل والحالة والوقود والسعر، بحث، وترتيب، ومفضلة.
- **تفاصيل السيارة**: معرض صور، مواصفات كاملة، حاسبة تقسيط، نموذج طلب عرض سعر، وسيارات مشابهة.
- **من نحن**: نبذة، أرقام، الخدمات، وخطوات الشراء.
- **تواصل معنا**: بيانات التواصل، خريطة، ونموذج مراسلة مع تحقق من المدخلات.

## التقنيات
HTML + CSS + JavaScript (بدون أي مكتبات أو خطوة بناء).

```
index.html      الهيكل العام (الهيدر، الفوتر)
css/style.css   التصميم والألوان (متغيرات CSS) والتجاوب
js/data.js      بيانات السيارات والخدمات (تُستبدل لاحقاً بـ API)
js/app.js       التوجيه بين الصفحات وبناء الواجهات والتفاعل
```

## التشغيل محلياً
```bash
python3 -m http.server 5173
```
ثم افتح http://localhost:5173

## ملاحظات
- الصور حالياً من Unsplash للعرض فقط، وتُستبدل بصور سيارات المعرض الفعلية.
- النماذج تتحقق من المدخلات فقط ولا ترسل بيانات بعد (مكان الربط معلَّم بـ `TODO` في `js/app.js`).
- الأسعار وبيانات التواصل تجريبية.
